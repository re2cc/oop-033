# Practica 7

La clase `PreservationThresholdViolatedException` representa una excepcion que se lanza cuando un valor para el umbral permitido por el coleccionable, por lo que contine el nombre del coleccionable, nombre del parametro, su valor y el umbral maximo permitido. Es decir asumiendo que esto estuviera funcionando la excepcion te indicaria exactamente que coleccionable y que parametro supero el umbral permitido.
